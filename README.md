# Mahindra Logistics — AI Operations Intelligence

Production deployment build for Mahindra Logistics AI Operations Intelligence Dashboard.

## Features Included
- AI Safety & PPE Monitoring
- Forklift–Pedestrian Alerts
- Fire & Smoke Detection
- Transport Safety & Fatigue Tracking
- Perimeter Intrusion & ANPR
- Yard & Dock Analytics
- Digital Guard Patrols
- Excel & PDF Export (ExcelJS, jsPDF, html2canvas)

## Deployment
This is a production-ready static bundle:
- Root directory (`./`) contains `index.html` and `assets/`.
- `dist/` directory also contains `index.html` and `assets/`.
Deployable with zero-config on Vercel, Netlify, or GitHub Pages.
